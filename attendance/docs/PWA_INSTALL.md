# Installing the owner dashboard (iPhone, iPad, Android, computer)

The dashboard is a Progressive Web App. You install it from the browser. No App Store or Google Play needed.

## iPhone / iPad (Safari)

1. Open **Safari** and go to your dashboard address, e.g. `https://attendance.yourdomain.com`.
2. Sign in.
3. Tap the **Share** button (square with an up-arrow).
4. Scroll and tap **Add to Home Screen** → **Add**.
5. Open it from the new home-screen icon. It runs full-screen like an app and stays signed in.

Notes: on iOS, installed web apps must be added from Safari (iOS 16.4+ also allows it from other browsers' share menu).
Email alerts reach you even when the app is closed. Live updates appear while the app is open.

## Android (Chrome)

1. Open **Chrome** and go to your dashboard address.
2. Sign in, then tap **Install app** in the banner or Settings → Install app. Or use the ⋮ menu → **Install app** /
   **Add to Home screen**.

## Computer (Chrome / Edge)

Click the install icon in the address bar, or ⋮ → **Install Attendance**. Any modern browser also works without installing.

## Updates

New versions install automatically. When one is ready the app shows **New version available → Reload**.

## Why not an iPhone app from the App Store?

Android APKs cannot run on iPhones. The PWA gives iPhone owners the same dashboard without App Store review. A native iOS
app would need an Apple Developer Program membership (US$99/year), code signing, and App Store review or Apple Business
Manager custom-app distribution. It is not needed for this product.
